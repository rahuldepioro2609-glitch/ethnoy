# Plus Jakarta Sans (bundled locally)

- Font: Plus Jakarta Sans, variable weight 200–800, upright only (the app uses no italics).
- Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans).
- Licence: SIL Open Font License 1.1, full text in `OFL.txt`, shipped beside the fonts.
- Source: npm package `@fontsource-variable/plus-jakarta-sans@5.3.0` (files/), unmodified.
- Subsets: `latin` and `latin-ext`. Devanagari, Kannada and Bengali text falls back to system fonts.
- Loaded by `@font-face` rules in `src/index.css`. No CDN or third-party request is made.
